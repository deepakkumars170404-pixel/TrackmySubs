## Password recovery

Set the Supabase project URL and publishable key in `frontend/.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your-publishable-key
NEXT_PUBLIC_BACKEND_URL=http://localhost:5000
```

The app provides `/forgot-password` and `/reset-password`. In Supabase Authentication settings, allow the frontend callback URL (for local development: `http://localhost:3000/reset-password`).

Forgot-password requests are sent through the backend API at `http://localhost:5000` by default. Set `NEXT_PUBLIC_BACKEND_URL` when the backend runs at another URL. The backend sends the recovery OTP and link using Resend.
